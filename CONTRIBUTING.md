# Contributing

- Read `AGENTS.md` and `ARCHITECTURE.md` before making changes.
- Preserve working web, PWA, offline-storage, and Android functionality.
- Work in focused branches and open pull requests. Do not rewrite published history.
- Prefer maintained open-source dependencies. Do not introduce proprietary app-builder tooling.
- Run `bun run build`, `bun run typecheck`, and `bun run lint` for web changes.
- Keep Android permission behaviour explicit and user-controlled.
- Never commit API keys, credentials, customer data, or personal information.
- Describe what changed and what was actually tested. Do not claim simulated or best-effort behaviour is fully autonomous.
